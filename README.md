Project purpose

Exam Helper is a university examination and practice-test platform with Student and Administrator roles.

Backup requirements

This repository is intended to hold a complete backup of the existing Exam Helper project, including:

- Source code and application configuration.
- Faculties, departments, academic levels, semesters and courses.
- Examination questions, answer keys and question-bank records.
- Examination settings, attempts, results and student profiles.
- Other supported application records and database exports.

Important instructions

Preserve the existing application, authentication, database records, configuration and deployment. Do not rebuild the project from scratch or overwrite existing data.

A source-code backup alone is not a complete database backup. Verify the exported records, check for truncation, and report any missing data. Never commit passwords, access tokens, API keys or other secrets to this repository.

Goal: Create and verify a recoverable backup of the existing Exam Helper application and its saved data.
